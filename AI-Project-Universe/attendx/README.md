# AttendX — Student Attendance Copilot

## Project files
- `index.html` — main application page
- `style.css` — application styling
- `script.js` — application logic and demo data

## How to run on Windows
1. Extract the ZIP file.
2. Open the `attendx-project` folder.
3. Double-click `index.html`.
4. If Windows asks which app to use, choose Google Chrome or Microsoft Edge.

The project is a client-side HTML/CSS/JavaScript application. No build step is required.
